# Coca-Cola Retailer Sales Analysis Dashboard 🥤📊

## Description

Professional Power BI dashboard analyzing $8.68M Coca-Cola sales across 17M units, 8 brands, and 5 regions. Interactive filters track monthly trends, brand performance, and retailer rankings with real-time KPIs. Perfect for managers and executives making data-driven decisions through dynamic visualizations and cross-filtering.
